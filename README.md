# CriptoLab Pro

Aplicação educacional em HTML, CSS e JavaScript puro para explorar cifras clássicas, codificações, hashes e análise de frequência.

## Recursos

- Cifra de César, Vigenère, ROT13, Atbash, XOR e inversão de texto
- Codificação e decodificação Base64, Binário e Hexadecimal
- Gerador de hashes SHA via Web Crypto API
- Análise de frequência de letras
- Histórico local no navegador
- Tema claro e escuro
